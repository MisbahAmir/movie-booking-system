# 🎬 Movie Booking System

## 📌 Description
A web-based movie ticket booking system developed using Laravel and PHP. Users can browse movies, select seats, and book tickets online.

## 🚀 Features
- User Registration & Login
- Movie Listings
- Seat Selection System
- Ticket Booking
- Admin Panel (optional)
- Responsive Design

## 🛠️ Technologies Used
- Laravel (PHP Framework)
- MySQL
- HTML, CSS, JavaScript
- Bootstrap
